# Точка роста

Интерактивный мобильный прототип по паспорту проекта v0.1 от 19 сентября 2026. Это PWA — веб-приложение для браузера и главного экрана телефона. Отдельного APK или приложения для App Store в этой версии нет.

## Открыть

Откройте index.html двойным щелчком. Основные сценарии работают без установки инструментов. Установка на телефон и офлайн-режим доступны после публикации по HTTPS или через локальный HTTP-сервер. Сохранение для file:// зависит от браузера; надёжнее проверять через HTTPS.

## Возможности

- Главная, книга, события, люди с нижним меню.
- Поиск по имени, профессии, сфере, полезности и запросу; фильтры.
- Карточки событий, расчёт взноса, запись и отмена, «Мои записи».
- Три состояния взноса: распределение расходов, бесплатно, уточняется.
- Пять типов реплик, фильтрация, добавление и удаление собственных.
- Профиль, локальное сохранение, сброс с подтверждением.
- Архив книг и макет двух фотоальбомов.
- Манифест, иконки, service worker для установки и офлайн-открытия.

## Границы

Люди, события, числа и расходы вымышлены. Книги настоящие, но выбор и вводный текст не утверждены. Реальных фотографий нет.

Telegram-вход, права доступа, общая база, настоящая запись, платежи, уведомления, админка и загрузка фото не подключены. Изменения находятся только в localStorage данного браузера, не видны другим людям и удаляются при очистке данных браузера. Настройка видимости профиля показывает будущую функцию.

Оплата после закрытия записи — гипотеза. Округление до 10 рублей взято из раздела 15 паспорта; порядок учёта разницы и отмен нужно согласовать. Форум, наставники, роли и личный прогресс оставлены для следующих этапов.

## Файлы

- index.html — каркас.
- app.css — оформление и адаптивность.
- data.js — редактируемые примеры данных.
- app.js — формы, навигация и сохранение.
- manifest.webmanifest, sw.js, icon* — установка и офлайн.
- GUIDE.md — публикация и управление.
- CHECKLIST.md — ручная приёмка.

Внешних библиотек, шрифтов и сборки нет. При изменениях увеличивайте VERSION в sw.js, например v1 → v2. После публикации откройте приложение онлайн и перезапустите.
## Проверка 26 сентября 2026

В фоновом Chrome пройдены 49 автоматических проверок: экраны, поиск, фильтры, расчёт взноса, запись и отмена, локальное сохранение, профиль, реплики, экранирование HTML и сброс. Проверена ширина содержимого 360, 390 и 430 px; основной экран просмотрен визуально.

Установка на реальный телефон, публикация GitHub Pages и офлайн-запуск после публикации ещё не проверены. Для них используйте CHECKLIST.md. Автоматические проверки не заменяют тест на телефоне.
