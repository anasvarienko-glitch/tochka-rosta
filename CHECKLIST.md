# Проверка перед публикацией

## Сценарии

- [ ] Переключить четыре пункта меню, проверить «Назад» браузера.
- [ ] Найти «команд» в людях, проверить фильтр «Продукт».
- [ ] Проверить пустой поиск и сброс.
- [ ] Открыть карточку человека, закрыть крестиком и Escape.
- [ ] Взнос: 25 человек = 600 ₽, 20 = 750 ₽, 18 = 840 ₽.
- [ ] Записаться: занято на одно место больше, свободно на одно меньше.
- [ ] Повторная запись не дублируется; отмена возвращает счётчики.
- [ ] Проверить бесплатное событие и уточняемый взнос.
- [ ] Проверить «Мои записи», включая пустое состояние.
- [ ] Сохранить профиль, обновить страницу, проверить сохранение.
- [ ] Добавить реплику «Вопрос», отфильтровать и удалить её.
- [ ] Реплика только из пробелов не добавляется.
- [ ] Символы < > & в формах отображаются как текст.
- [ ] В галерее явно показаны заглушки.
- [ ] Отменить сброс, затем подтвердить сброс.

## Устройства и публикация

- [ ] На ширине 360–430 px нет горизонтальной прокрутки.
- [ ] Нижнее меню не перекрывает последние кнопки.
- [ ] Проверить клавиатуру и прокрутку диалогов.
- [ ] На Pages доступны CSS, JS, иконки и манифест под /tochka-rosta/.
- [ ] Добавить на телефон с опубликованного HTTPS-адреса.
- [ ] После открытия онлайн проверить повторный запуск без сети.
- [ ] После увеличения VERSION проверить обновление онлайн.
- [ ] На другом устройстве локальные записи не появляются: ожидаемое ограничение.
