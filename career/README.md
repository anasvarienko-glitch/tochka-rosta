# Сайт-визитка Яны Оленяк

Сайт карьерного консультанта: первый экран с фото, обо мне и три роли, фразы клиентов, диагностика, пакеты из 3 и 5 консультаций, направления, опыт, шаги работы, вопросы, контакты.

Чтобы заменить фото на первом экране, положите новый файл в `assets/` и поменяйте путь в `index.html` (блок `hero-photo`).

Адрес: https://anasvarienko-glitch.github.io/tochka-rosta/career/

## Файлы

- `index.html` — весь текст сайта. Правьте его, чтобы изменить содержание.
- `style.css` — оформление (цвета заданы в начале файла).
- `app.js` — меню на телефоне, переворот фраз клиентов, плавное появление блоков.
- `assets/` — логотип (`mark.png`) и фото (`yana.jpg`, оно же картинка для соцсетей).

Сборка не нужна. После изменений сделайте commit и push в GitHub Desktop — GitHub Pages обновит сайт за 1–2 минуты. Если браузер показывает старую версию, увеличьте `?v=1` у `style.css` и `app.js` в `index.html`.

## Что стоит дополнить

- Цены пакетов и длительность встреч (раздел «Пакеты»).
- Второе фото в другой позе для первого экрана.
- Отзывы клиентов (с их согласия).
- Образование и сертификаты.

## Результат диагностической встречи

По итогам диагностики клиент получает сформированный список улучшений и действий для поиска работы, карьерный план и рекомендации по последовательности шагов. В описании услуги не заявляется бесплатная диагностика. Уточнены блок диагностики, шаги работы и финальный призыв к записи.
