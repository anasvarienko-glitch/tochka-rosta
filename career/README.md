# Сайт-визитка Яны Оленяк

Сайт карьерного консультанта: обо мне, опыт и портфолио, с чем работаю, форматы, как проходит работа, вопросы, контакты.

Адрес: https://anasvarienko-glitch.github.io/tochka-rosta/career/

## Файлы

- `index.html` — весь текст сайта. Правьте его, чтобы изменить содержание.
- `style.css` — оформление (цвета заданы в начале файла).
- `app.js` — меню на телефоне, переворот фраз клиентов, плавное появление блоков.
- `assets/` — логотип (`mark.png`), фото (`yana.jpg`), фон первого экрана (`hero.jpg`), картинка для соцсетей (`og.jpg`).

Сборка не нужна. После изменений сделайте commit и push в GitHub Desktop — GitHub Pages обновит сайт за 1–2 минуты. Если браузер показывает старую версию, увеличьте `?v=1` у `style.css` и `app.js` в `index.html`.

## Что стоит дополнить

- Цены и длительность встреч в разделе «Форматы».
- Отзывы клиентов (с их согласия).
- Образование и сертификаты.
